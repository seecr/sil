# Security

sil indexes your data and parses the queries of your users, so we take security problems
seriously.

## Reporting a problem

Please don't report security problems in a public issue. Instead, use
[private vulnerability reporting](https://github.com/seecr/sil/security/advisories/new)
on GitHub. Tell us what you found, which version of sil it affects, and how to
reproduce it.

We will confirm that we received your report, keep you informed while we work on a fix,
and credit you in the release notes unless you prefer not to be named.

## Supported versions

Security fixes go into the latest release. Upgrade to the newest version on
[PyPI](https://pypi.org/project/seecr-sil/) to get them.
